# 探秘！试管婴儿实验室胚胎优选

> 更新时间：2026-09-11 (UTC+8)

“在试管婴儿实验室卵子和精子经过处理，通过自然结合（一代试管）或人为结合（二代试管）形成的受精卵称为胚胎。”威海市妇幼保健院生殖健康科副主任、实验室主任刘吉介绍，胚胎还需要在实验室培养2-7天，才能形成卵裂胚胎或囊胚。**对于尝试“试管婴儿”方式助孕的患者，****移植前的胚胎优选至关重要。**

等级 / 哪些胚胎是优质胚胎

**胚胎是如何分级的**

胚胎可以根据发育速度、卵裂球的大小及碎片的多少，分为不同的级别。D3天的卵裂期胚胎分为4个级别。I级是指卵裂球大小均匀，碎片小于10%；II级是卵裂球大小较均匀，碎片在10%-20%之间的胚胎；III级是指卵裂球大小不均匀，碎片在20%-50%之间；IV级是指卵裂球大小极不均匀，碎片在50%以上的胚胎。

囊胚的分级相对复杂些。首先，根据囊胚腔的大小及是否孵化，将囊胚的发育分为六个时期，再根据内细胞团大小及紧密程度分为3个级别（A、B、C级），最后，根据滋养层细胞数及形态分为3个级别（A、B、C级）。”如4AA的囊胚，胚胎处于扩展的4期，内细胞团较大，为最高级A级，滋养层细胞较多、分布均匀，为最高级A级。

刘吉介绍，“根据专家共识，优质胚胎定义为来源于正常受精卵的第三天7-9细胞2级以上的胚胎；优质囊胚定义为4期及以上，内细胞团及滋养层细胞达到B级及以上的囊胚。”

碎片 / 胚胎碎片影响成功率吗

**试管婴儿成功率**

“胚胎碎片是早期胚胎发育过程中的常见现象，有些人一听到碎片两个字就害怕，其实大可不必。”刘吉介绍，胚胎碎片是从受精卵或早期胚胎中排出的由细胞膜包裹的、没有细胞核的胞浆结构。部分碎片在胚胎的分裂过程中，可以通过消融或者卵裂球的重吸收等机制消失。

胚胎碎片的多少、大小和分布与胚胎发育潜能、胚胎着床率及临床妊娠率有密切的关系。**碎片越多的胚胎，发育潜力可能越差，**大于50%的碎片，通常认定为不可利用胚胎。

优选 / 哪种胚胎移植成功率高

** 胚胎移植优选**

刘吉介绍，“卵裂期胚胎要看胚胎的发育速度、卵裂球的形态及胚胎的碎片率。正常情况下，在精子和卵子完成受精后，第二天发育到4-6细胞，第三天应该有7-9细胞。如果胚胎发育迟缓或生长过快，胚胎种植率会降低。”

如果试管婴儿患者第三天移植，建议选择2枚7-9细胞、卵裂球均匀、碎片低于10%的优质胚胎，或者可以选择细胞发育速度较快，卵裂球均匀，碎片较少的胚胎进行移植。

如果选择囊胚移植，试管婴儿实验室胚胎学专家要看这枚囊胚的发育速度、内细胞和滋养层细胞的数量和形态。正常情况下，受精卵发育到第5天，胚胎会发育到囊腔较大、内细胞团较大、较紧密、滋养层细胞较多，分布均匀的扩张囊胚。刘吉建议，此时患者进行胚胎移植，可选择一枚囊胚（4BB及以上）的进行移植。也可以选择4BC或4CB相对较差的胚胎移植，通常成功率较高。

受孕 / 为啥囊胚移植的成功率高

**胚胎移植的成功率**

说到囊胚，得先了解一下什么是囊胚。通俗一点说就是精卵结合后，发育到第5天形成的胚胎。囊胚移植成功率高，主要有两个方面原因。

首先，如果胚胎发育潜能差或携带有异常的染色体和基因时，在延长培养的过程中，胚胎可因自身发育异常而被自然淘汰，只有质量最好的胚胎，最终才能发育成囊胚；

其次，选择胚胎在“囊胚期”移植，子宫宫腔可以提供一个更接近生殖生理的自然环境，这样的胚胎具有较高的种植能力和成功率。
